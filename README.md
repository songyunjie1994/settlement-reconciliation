# 安必拓结算对账

网址：https://songyunjie1994.github.io/settlement-reconciliation/

GitHub Pages 托管页面，Supabase 保存订单、结算明细和采集记录。仓库不含订单、原始账单、登录态或采集凭据。使用已有系统邮箱账号登录；只有数据库成员名单中的账号可读。

## 开发与发布

Node.js 22.13+，执行 `npm ci`、`npm run check`、`npm run build`。推送 main 后 GitHub Actions 发布 dist。

## 数据库

`backend/schema.sql` 仅定义本系统表和 RPC，不修改其他业务表。部署时通过管理通道添加 `settlement_members` 成员和 `settlement_collector_keys` 哈希。所有表启用 RLS，匿名和普通用户不能直接读取表；查询 RPC 校验登录用户及成员资格。采集入口使用独立随机凭据，仅授予本系统回传和数量核验能力，数据库只保存 SHA-256。采集机在当前 Windows 用户 DPAPI 下保存凭据。

## 业务口径

- 快手按订单时间，抖店联盟按付款时间归属月份。首次范围 2026-06-18 至 2026-10-18，补采的历史订单另保留原月份。
- 达人昵称、平台账号、平台数值 ID 分别保存，团长昵称对应服务机构；缺失显示 `—`。
- 金额按整数分存储。缺失金额保持 null。
- “未确认完结”表示尚未取得平台明确最终状态，不能直接当作漏结算。超过四个月也不会自动关闭。
- 当前采集机每日任务仍待正式部署启用。

## 验证

发布前检查 TypeScript 和生产构建；验证匿名不能读取数据，错误采集凭据不能写入，同批次重复回传不增加记录，过期快照不会覆盖新记录。源数据数量与数据库平台计数独立核对。
